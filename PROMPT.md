# Prompt para crear Duolingo matemático

Actúa como desarrollador web junior guiado. Crea una aplicación educativa de preguntas llamada **Reto Matemático** usando HTML, CSS y JavaScript vanilla. No copies nombres, logotipos ni recursos de Duolingo; usa identidad visual propia.

Incluye exactamente 20 preguntas apropiadas para sexto de primaria: sumas, restas, multiplicaciones, divisiones y problemas cortos. Muestra una pregunta a la vez y cuatro opciones. Debe existir una respuesta correcta por pregunta. Al responder, informa si fue correcta o incorrecta antes de continuar.

Muestra el avance `Pregunta X de 20`, puntuación y tres vidas. Las respuestas incorrectas reducen una vida. Al terminar las 20 preguntas o perder las vidas, muestra una pantalla de resultado con aciertos, porcentaje y un mensaje. Incluye botón para reiniciar el reto.

Organiza el proyecto en `index.html`, `css/styles.css` y `js/app.js`. Define las preguntas en un arreglo de objetos y mantén la lógica separada de la interfaz. Lee `PLAN.md`, `DESIGN.md` y `AGENTS.md` antes de comenzar. No generes preguntas que tengan resultados ambiguos ni respuestas duplicadas.
